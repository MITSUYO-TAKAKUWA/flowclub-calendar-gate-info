ホームプライバシーポリシー利用条件

プライバシーポリシー / Privacy Policy

最終更新日：2026年10月26日

1. 運営・対象

Flow Club Calendar Gateは、開発者本人のMacでのみ使用する個人用デスクトップ自動化プログラムです。第三者向けの登録サービスではありません。

2. アクセスするGoogleユーザーデータ

OAuth権限 https://www.googleapis.com/auth/calendar.events.readonly を用いて、Google Calendarに保存された予定情報を読み取ります。Flow Clubの予約を識別するため、予定名、開始・終了日時、場所・ルームURL、予定の確定・キャンセル状態、参加者による応答状態を参照することがあります。カレンダーの内容を変更する権限は要求しません。

3. 利用目的と処理方法

予定が所定のFlow Clubホストセッションと一致するかを一時的に照合し、一致した場合に限りMac内の集中タイマーを起動します。イベント情報はローカルメモリ内で処理し、Google Calendarから取得した予定本文を独自サーバーや公開データベースには転送しません。

4. 保存と保持期間

OAuthクライアントの設定とアクセストークン・更新トークンは、開発者本人のMacのアクセス制限されたローカルフォルダーに保存します。APIから取得した個別予定の本文は恒久保存せず、照合後にメモリから破棄されます。認証ファイルは、アプリの利用終了時にローカル端末から削除できます。

5. 共有・販売

このアプリは、Google Calendarの予定情報を広告会社、データブローカー、その他の第三者へ販売・共有しません。Google OAuth認証とGoogle Calendar APIへの通信はGoogleのサービスとの間で発生します。公開サイト自体は静的ページであり、カレンダー情報を受信しません。

6. セキュリティ

必要最小限の読み取り専用権限を使用し、認証トークンはMac上のアクセス制限付きファイルに保存します。プライベート認証情報は公開ソースコードや本サイトに含めません。

7. 権限の撤回・問い合わせ

Googleアカウントの接続済みアプリ管理ページからいつでもアクセスを取り消せます。個人用アプリに関する問い合わせ先は、Google OAuth同意画面に表示されるユーザーサポート用メールアドレスです。

8. 変更

この方針を変更する場合は本ページの日付・内容を更新します。

English summary

Flow Club Calendar Gate is a single-user, Mac-local tool. It requests only calendar.events.readonly to inspect Google Calendar event titles, schedules, status and Flow Club room links so that the local focus timer runs only for confirmed reservations. Calendar events are processed in memory, not retained in an app database and not sold or shared with third-party advertisers. OAuth credentials are saved locally with restricted file permissions. This static website receives no Google Calendar event data. Revoke access at Google Account connections. For contact, use the support email shown on the Google OAuth consent screen.
